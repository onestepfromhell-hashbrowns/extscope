ExtScope

Declare which tools, skills and rules a container or agent account gets. ExtScope checks the declaration, plans the work, and copies the files.

WorkflowPackagesLayersDirectoriesQuick start

Workflow

Green boxes only read. Orange boxes write.

Packages

Each package uses only the standard library. No package imports another. They share JSON files only.

extscope

read-only

Validate, plan, bind, verify, query.

extscope-dist

writes

Copy or link to host targets. Backup and rollback.

extscope-modules

writes

Optional steps: mode, owner, key, environment, hook, import.

extscope-container

writes

Move files into containers. Leases and cleanup.

extscope-harness

plans only

Choose the target path for each agent platform.

extscope-tools

read-only

Secret and mount scan. Anomaly ledger. Layer check.

Layers

A higher layer can depend on a lower layer. The reverse is an error.

Quick start

pip install .
extscope validate --scope /abs/path/my-tool.extscope.json
extscope plan     --scope /abs/path/my-blueprint.extscope.json --entry <entry>
extscope-dist plan  --receipt receipt.json
extscope-dist apply --receipt receipt.json
Safety rules
  • The core is read-only. It rejects symbolic links in declarations.
  • extscope-dist locks each target directory, backs up first, and rolls back if a step fails.
  • extscope-dist prune deletes old backups only with --apply.
  • Errors are short. Set EXTSCOPE_DEBUG=1 to see details.
